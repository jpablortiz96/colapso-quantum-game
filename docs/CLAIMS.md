# Scientific and Technical Claims Register

This table governs copy, documentation, evidence, demos, submissions, and generated reports. “Allowed” always means allowed only when the stated evidence exists. Game terminology is a metaphor unless a row explicitly refers to a measured workload.

## Mandatory correction

A one-basis `00`/`11` correlation does not establish physical entanglement or a Bell violation. Only the separate, predeclared multi-basis CHSH workflow may compare its measured witness and uncertainty with the classical bound `2`.

## Review rule

Before publishing a scientific or technical claim, identify its row, verify every required artifact in `docs/EVIDENCE.md`, and use wording no stronger than the evidence. If no row fits, add a reviewed row before publication. Absence of evidence requires removing or weakening the claim, never inventing a metric or result.
